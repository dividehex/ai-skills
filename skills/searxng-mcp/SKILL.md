# Searxng Mcp

Use this skill when searching the web.

## Instructions

### Web research
Use the SearXNG MCP web-search tool when a task requires current information, external documentation, component datasheets, hardware specifications, or software compatibility verification.
Prefer official documentation and manufacturer datasheets. Provide source URLs for technical claims. Do not invent specifications or claim that a source was verified when it was not.
Search results are discovery information, not verified full-document content. Retrieve and inspect the original source when the task requires detailed specifications.
