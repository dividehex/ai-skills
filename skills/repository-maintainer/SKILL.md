# Repository maintainer

Use this skill when maintaining the shared skills repository itself.

Keep canonical skill instructions vendor-neutral and suitable for a public
repository. Put integration-specific details in the repository documentation or
sync tooling. Before a release, validate every skill, review for secrets and
private paths, update the changelog, and use a deliberate semantic-version tag.

When a user or project instruction conflicts with this skill, follow the user
or project instruction.
